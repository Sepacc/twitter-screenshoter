Применяется к скриншотам и записи видео. Для мониторов 1366×768 идеален режим 2x (~1200px, чёткий текст и интерфейс без мыла). Режим 3x предназначен для экранов FullHD/4K.

Записывать субтитры на видео
MP4 (H.264) идеален для Telegram (автовоспроизведение и циклы в чатах). При запуске stitcher.py конвертируется через FFmpeg без потери качества.
Высота цитаты по умолчанию
Обрезает нижний пост (цитату), убирая огромные картинки и освобождая место под видео. Также настраивается ползунком прямо в меню твита.
Подпапка в «Загрузках»:
Всегда открывать выбор папки (Save As)
Файлы сохраняются в Загрузки/<подпапка>/. Тумблер открывает стандартное окно Windows для выбора любой папки.
Только если открытый пост — цитата
Кнопка с меню (Этот пост / Вся ветка) добавляется только на странице открытого поста. В общей ленте и комментариях посторонних пользователей кнопка не отображается.
